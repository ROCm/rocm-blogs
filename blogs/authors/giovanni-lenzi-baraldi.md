# Giovanni Lenzi Baraldi

Giovanni Lenzi Baraldi is a SMTS Software Development Engineer at AMD's ROCm Profiler team, focused on intra-kernel profiling, low-level optimization and thread trace (ATT/SQTT).

Prior to joining AMD, Giovanni worked on X-ray detectors, X-ray fluorescence, computed tomography and ptychographic CDI with a focus on building optimized GPU software for image reconstruction.
Giovanni holds a BSc in Physics from the State University of Campinas.
