# Adel Johar

Adel Johar is a software engineer at AMD with more than ten years of experience working with GPUs. His work has spanned parallel algorithms, GPU libraries, scientific application porting, and performance analysis across the software stack. He has contributed to the ROCm™ rocPRIM and rocRAND libraries and ported and optimized scientific applications for AMD Instinct™ GPUs.
