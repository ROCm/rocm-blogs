# Arthur Huang

Arthur Huang is an SMTS Software Development Engineer in the AI Group of AMD. He manages an inference optimization team focused on accelerating large language model inference on AMD Instinct GPUs. His work covers LLM serving performance, GPU kernel optimization, distributed inference, and framework integration for systems such as SGLang and vLLM.
