# Omar Muhammad

Omar Muhammad is a software engineer at AMD on the machine learning frameworks team. He develops high-performance kernels for AITER in Triton, Gluon, and FlyDSL, which are in turn used in LLM serving frameworks such as ATOM and vLLM.
