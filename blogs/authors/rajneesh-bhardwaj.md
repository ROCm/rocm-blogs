# Rajneesh Bhardwaj

Rajneesh Bhardwaj is a System Software Architect for AMD Instinct accelerators.

He is Working on enabling, maintaining and optimizing HPC and AI compute architecture for
optimal performance for the exascale computing based on AMD accelerators. He works across
boundaries of hardware software switching between low level details to user space across
the system software stack. He worked on AMD GPU driver to enable MI300A unified memory
architecture and implemented several key features in the driver.

Prior to that, he played a key role in enabling world’s first transparent real world
checkpoint restore solution with AMD GPUs using CRIU https://www.criu.org/Main_Page for
compute workloads like pytorch and tensor flow models for live migration of GPU work loads.

He also specialized in Linux kernel power management and is the author and maintainer of Intel
power management controller driver.
