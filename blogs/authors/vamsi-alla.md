# Vamsi Alla

Vamsi Alla is a Fellow Silicon Design Engineer at AMD, working in IP and SOC architecture. Vamsi focuses on the memory and compute architecture of AMD Instinct GPUs, including the memory hierarchy and reliability features built into the AMD CDNA architecture.
