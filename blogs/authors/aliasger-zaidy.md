# Aliasger Zaidy

Aliasger Zaidy is a software engineer at AMD working on LLM inference performance for Instinct GPUs. He works on Triton/Gluon kernel development, performance analysis, and optimization in [AITER](https://github.com/ROCm/aiter), AMD's ML operators library. His work spans from kernel level through end-to-end serving, bringing AMD's software stack to LLM serving frameworks such as ATOM, vLLM and SGLang.
