# Felix Marty

Felix Marty is a software engineer specialized in deep learning model compression, working on AMD Quark open-source model compression toolkit, and contributing to algorithms, evaluations, hardware deployment and open-source integrations. Prior to AMD, he used to work at Hugging Face on Optimum, Transformers and text-generation-inference libraries.
