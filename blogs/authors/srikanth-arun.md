# Srikanth Arun

Srikanth Arun is a software engineer focused on ML infrastructure, GPU model serving, and immersive (WebXR / VR) applications. He writes about hands-on experiments with the ROCm stack — serving large language and vision-language models with vLLM on AMD Instinct GPUs, and building AI-assisted developer tooling on top of them.

His current interests sit at the intersection of self-hosted LLMs and software quality: using vision-language models to propose tests from application screenshots, then verifying those proposals against deterministic oracles so only trustworthy tests reach CI.
