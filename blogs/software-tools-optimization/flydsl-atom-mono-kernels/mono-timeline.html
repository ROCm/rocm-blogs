Capture scope

This trace records 1,062 task intervals per layer on 256 active logical blocks. Each layer has its own zero-based clock. No indexer stages, model shape, context length, precision, TP count, or source revision are recorded. The capture illustrates scheduling; its timing is separate from the full-indexer benchmark in the blog.

Logical block = (stage base + task ID) % 256. This mapping was checked against a one-to-one correspondence with the trace's active hardware-lane IDs in all three layers. Overlapping task spans include dependency waits and do not measure GPU utilization.
